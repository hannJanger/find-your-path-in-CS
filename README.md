# Find Your Path in CS

A simple career-domain quiz designed to help beginners explore different areas of Computer Science based on their interests.

## About

The quiz includes simple questions about interests and preferences and provides a suggested Computer Science career path based on the answers.

## Technologies Used

* HTML
* CSS
* JavaScript

## Features

* Simple and interactive quiz
* Beginner-friendly questions
* Multiple Computer Science career paths
* Personalized results
